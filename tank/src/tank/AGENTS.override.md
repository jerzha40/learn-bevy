# AGENTS.md

## 项目总览

- 类似星露谷物语那种视角的坦克大战。
- 玩家操控一个坦克。
- Engine: Bevy.
- Keep changes small and shippable.

## Repo layout(仓库结构)

- /tank: 坦克预制件

## 编码与改动规则（Coding rules）

- 尽量最小化 diff：能局部改就不要大范围重构。
- 未经明确要求，不要引入新的依赖、插件或第三方库。
- 优先遵循现有代码风格与目录约定；如果仓库里没有统一风格，就保持本次改动内部一致。
- 修改后确保项目能打开/运行；若涉及场景与资源引用，注意 Godot 的路径与导入设置。

### 沟通输出要求（给 Codex 的要求）

- 任何不确定点：先给出 1-2 个方案对比（优缺点/风险），并说明你选择的默认方案。
- 对关键改动：写清楚“改了什么”“为什么这样改”“如何验证”。

## 安全区/禁止改动（Safety / do-not-touch）

- 未经要求，不要修改 CI、发布配置（例如 `.github/`、导出流水线、release 脚本等）。
- 不要无理由重写大文件（尤其是场景文件、自动生成文件、资源导入文件），避免巨大 diff。
- 不要随意改动项目全局设置（Project Settings / Input Map / 渲染设置等），除非任务明确需要，并在说明中列出改动项。
