# windowblob

## 目标

制作一个世界泡（预制件）。  
世界泡就是一个不同大小的窗口，坦克可以进入窗口（世界泡）内。  

## 实现接口说明

为了我可以方便进行游戏设计，每个世界泡在存档中是单独保存的，包括里面所有实体位置。  
因为世界泡由传送门连接，玩家可以选中传送门，传送门就会要求开启新的窗口，玩家离开旧窗口不会自动关闭，玩家可以选择稍后自己关闭。

不同世界泡有不同大小，玩家不能走出这个虚拟世界泡边界（渲染上就是窗口边界），我们要设计一个虚拟世界度量bm（blob meter）来决定坦克在世界中的渲染大小和相对关系。

有一个每个玩家可以自己设置，以后制作相机跟随时也可也制作的参数
pixel_per_bm为逻辑单位对应渲染像素单位的换算关系。

主世界就是一个默认世界泡，叫存档是main.blob.json，玩家出生在中心，主世界泡大小是10bm*10bm
